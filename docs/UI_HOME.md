# ホーム画面 仕様

ログイン後に最初に表示される画面。AWS マネジメントコンソールのトップに相当する。
**この画面はチャットではない。** アプリの入口とシステム状態の確認に徹する。

参考画像: `docs/assets/home-mockup.png`

---

## フロントエンド構成（Phase 1 で確定）

- React 18 + TypeScript + Vite
- ルーティング: React Router
- スタイル: Tailwind CSS
- 状態管理: ライブラリを入れない。`useState` と fetch ラッパーで足りる範囲に留める
- ビルド成果物を `console` コンテナから配信し、`proxy` が `/` にルーティングする

**UI ライブラリ（MUI / Chakra 等）を導入しないこと。** 画面数が少なく、
既定テーマの見た目が強く出て後から剥がすのが高くつく。

---

## 画面構成

上から順に4ブロック。**縦1カラム、最大幅 960px、中央寄せ。**

### 1. ヘッダー

- 左: CPUアイコン ＋ `LLM Console`
- 右: ログイン中ユーザー名 ＋ イニシャルのアバター円（クリックでメニュー、ログアウト）
- 下辺に 1px のボーダー

### 2. システム状態パネル

薄いグレー地のパネル（カードではない。枠線なし）。

| 表示項目 | データ元 |
|---|---|
| 稼働状態のドット ＋ テキスト | `GET /api/admin/health` |
| GPU 名 | `GET /api/admin/gpu` の `name` |
| VRAM 使用量 `3.4 / 8.0 GB` | 同上 `memory_used_mb` / `memory_total_mb` |
| 使用率バー | 同上から算出 |
| 読み込み中のモデル | `/api/admin/health` の `llm.loaded_models` |

- **30秒ごとにポーリングして更新する。** WebSocket は使わない
- バー色は使用率で変える: 〜70% 通常 / 70〜85% 警告 / 85%〜 危険
- API が落ちている場合はドットを赤にし、数値は `—` を表示する。**画面全体を壊さないこと**
- モデル未ロード時は「モデル未読み込み」と表示（エラー扱いにしない。アイドルで解放された正常状態）

**このパネルは一般ユーザーにも表示する。** 管理者限定にしない。
他の人が重い処理を流しているかを全員が判断できることが目的。

### 3. アプリ一覧

見出し「アプリ」＋ カードのグリッド。デスクトップ3列、タブレット2列、モバイル1列。

カード1枚の構成: アイコン / 名称 / 1行説明 / 状態バッジ

| 名称 | アイコン | 説明 | 状態 | 遷移先 |
|---|---|---|---|---|
| プレイグラウンド | message-circle | モデルを選んで対話する | 利用可能 | `/playground` |
| 社内文書検索 | file-search | 資料を読み込んで質問する | Phase 2 | 無効 |
| 文字起こし | microphone | 録音から議事録を作る | Phase 2 | 無効 |
| API キー | key | 外部ツールから接続する | 利用可能 | `/api-keys` |

- **未実装アプリもカードを表示する。** バッジで状態を示し、クリックは無効化する
  （カード全体の不透明度を下げ、`cursor: default`。押しても何も起きない）
- 状態バッジは2種類のみ: 緑「利用可能」/ 青「Phase 2」

### 4. 管理セクション

**`admin` ロールのときのみ表示。** `user` ロールには存在自体を見せない。

カードではなく、区切り線で仕切ったリスト行。各行は アイコン / 名称 / 右端に件数。

| 名称 | 右端の値 | 遷移先 |
|---|---|---|
| ユーザー管理 | 有効ユーザー数 | `/admin/users` |
| モデル管理 | 有効モデル数 | `/admin/models` |
| 利用状況 | 当日の合計トークン数 | `/admin/usage` |

件数は `GET /api/admin/summary` で1回にまとめて取得する（3回叩かない）。
このエンドポイントは未実装なので、本タスクで追加すること。

## 守ってほしいこと

- **ダークモード対応。** 色をハードコードせず CSS 変数か Tailwind の `dark:` を使う
- **数値は必ず丸める。** VRAM は小数1桁、トークン数は `toLocaleString()`
- 初回読み込み中はスケルトンを出す。スピナーで画面全体を覆わない
- 文言は日本語。ボタンは動詞から始める。感嘆符を使わない
- 認証切れ（`401`）を受けたらログイン画面へリダイレクトする

## やらないこと

- ホーム画面にチャット入力欄を置かない
- グラフやチャートを置かない（利用状況は `/admin/usage` の担当）
- 通知・お知らせ欄を作らない
